# Mobile Legal AI Assistant

## Goal

An offline Android application that allows users to:

- Chat with a local LLM
- Upload legal documents
- Summarize documents
- Ask questions about documents
- Operate without internet

## Tech Stack

Frontend:
- React Native

AI:
- llama.cpp
- Qwen 2.5 3B (GGUF)

Future Features:
- Local document search
- Voice input
- Multi-document analysis
