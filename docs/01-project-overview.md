# Mobile Legal AI Assistant - MVP

## Goal

Provide an offline AI assistant for legal and accounting documents on Android.

## Version 1 Features

### Chat

- User enters a question
- Local LLM generates a response

### Document Upload

- Upload PDF files
- Store PDFs locally

### Document Summarization

- Generate summary of uploaded PDF

### Ask Document

- Ask questions about uploaded PDF

Examples:

- What is clause 5?
- Who are the parties involved?
- What are the important dates?

## Not Included In V1

- Cloud sync
- User accounts
- Multi-user support
- Online AI APIs
- Voice input
- OCR for scanned documents

## Target Device

- Android
- 12GB RAM

## Local Model

- Qwen 2.5 3B GGUF
